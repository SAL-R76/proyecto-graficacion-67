Inspector visual del árbol DOM

Selecciona cualquiera de las ocho páginas para explorar su estructura real: desde <html> hasta <head>, <body>, regiones semánticas y elementos hijos como <h1>, <p> y <canvas>.

Cada recuadro representa una etiqueta HTML o un nodo de texto. Las líneas expresan relaciones padre-hijo. Los nodos semánticos aparecen en morado. El árbol se genera leyendo el HTML real de cada archivo, no mediante una ilustración fija.

¿Qué es el DOM?

El Document Object Model (DOM) representa un documento HTML como un árbol de nodos. El elemento html es la raíz y contiene head y body. A su vez, body incluye encabezados, navegación, contenido principal y pie de página. JavaScript puede consultar y modificar estos nodos con métodos como querySelector() y append().

Importante: abre este proyecto desde un servidor local (por ejemplo, Live Server de VS Code) o GitHub Pages. Los navegadores pueden bloquear fetch() entre archivos al abrirlos con file://.
