Fundamentos de graficación web

De los comandos de dibujo de Khan Academy al navegador: tecnologías, coordenadas, contextos y animación interactiva.

1. ¿Qué es HTML Canvas?

La etiqueta <canvas> define una superficie rectangular de píxeles dentro de una página HTML. Por sí sola no dibuja: JavaScript obtiene un contexto de renderizado y ejecuta instrucciones para crear figuras, texto, imágenes y animaciones. Los atributos width y height determinan la resolución interna; el CSS puede modificar su tamaño visual.

<canvas id="lienzo" width="400" height="400"></canvas>

Contexto de renderizado 2D

canvas.getContext('2d') proporciona una interfaz para dibujar con coordenadas cartesianas cuyo origen (0,0) está en la esquina superior izquierda. El eje X aumenta hacia la derecha y el Y hacia abajo. Entre sus operaciones destacan fillRect(), strokeRect(), beginPath(), ellipse(), lineTo(), fill() y stroke(). Los colores se configuran mediante fillStyle y strokeStyle.

const canvas = document.querySelector('canvas');
const ctx = canvas.getContext('2d');
ctx.fillStyle = '#36c7ff';
ctx.fillRect(0, 0, 400, 400);
ctx.fillStyle = '#ffbd00';
ctx.beginPath();
ctx.arc(80, 65, 50, 0, Math.PI * 2);
ctx.fill();

Canvas es un mapa de píxeles: las formas dibujadas no se convierten automáticamente en elementos HTML individuales. Para cambiar una escena, normalmente se limpia el lienzo y se vuelve a dibujar.

2. ¿Qué es p5.js?

p5.js es una biblioteca de JavaScript orientada a programación creativa, arte digital, visualización y enseñanza. Simplifica tareas de Canvas mediante funciones como createCanvas(), background(), ellipse(), rect(), fill() y stroke(). La función setup() prepara el lienzo una sola vez; draw() se ejecuta repetidamente para producir animaciones.

function setup() {
  createCanvas(400, 400);
}
function draw() {
  background(0, 200, 255);
  fill(255, 187, 0);
  ellipse(mouseX, 80, 100, 100);
}

Este ejemplo sigue el puntero del ratón con el sol. Para ejecutarlo es necesario cargar la biblioteca p5.js. En este proyecto, los cinco gráficos se implementan directamente con Canvas 2D, sin dependencias externas. En las páginas de cada dibujo también puedes consultar sus instrucciones de programación.

Relación entre Khan Academy, p5.js y Canvas

En los ejercicios se utilizan comandos de estilo ProcessingJS, como ellipse(x,y,w,h) y background(r,g,b). p5.js ofrece comandos similares, aunque no es exactamente el mismo entorno. Canvas 2D nativo usa métodos diferentes; por ejemplo, una elipse requiere construir una ruta con ctx.ellipse() y luego rellenarla. Por ello, los dibujos se adaptaron con funciones auxiliares equivalentes.

3. Interactividad, animación y buenas prácticas

Los eventos input y change permiten modificar variables a partir de controles. Cada cambio actualiza el estado y vuelve a renderizar el gráfico. Para animaciones continuas, requestAnimationFrame() sincroniza el redibujado con el navegador. Es importante separar HTML (estructura), CSS (presentación) y JavaScript (comportamiento), añadir etiquetas accesibles y comprobar el resultado en pantallas pequeñas.

Ejemplo de animación con Canvas nativo

let x = 0;
function animar() {
  ctx.clearRect(0, 0, 400, 400);
  ctx.fillRect(x, 100, 40, 40);
  x = (x + 2) % 400;
  requestAnimationFrame(animar);
}
animar();
